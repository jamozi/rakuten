# ST-0903 — deterministic immutable publication snapshot

## Objective

Implement the Canonical ST-0903 output locally from exact recorded dependencies
without crossing the publication boundary. The implementation produces an
immutable content manifest and snapshot candidate and proves deterministic
replay, exact dependency binding, idempotency, and fail-closed behavior.

## Canonical inputs

- ST-0902 recorded final approval for one exact article version and AST hash.
- ST-0807 route-only preview metadata, noindex/nofollow controls, and allowed
  Article JSON-LD with prohibited commerce/review schema types disabled.
- ST-0808 clean-quarantined synthetic media projected only as an admin-only
  reference, never as renderer input or public media.
- Canonical publication content-manifest and publication-snapshot contracts,
  security controls, TST-014, and TST-021.

## Implementation boundary

1. Rebuild each recorded dependency from its owner fixture.
2. Bind exact AST, source packet, candidate universe, methodology, policy,
   quality, approval, SEO, structured-data, and media hashes.
3. Build canonical JSON deterministically. The snapshot self-hash excludes only
   the `snapshot_sha256` field; the final serialized artifact has a second hash.
4. Return an immutable process-local candidate through provider-neutral ports.
5. Refuse non-local environments, drift, arbitrary collaborator outcomes,
   idempotency conflicts, prohibited material, and any authority escalation.

The legacy common snapshot schema embeds an obsolete AST shape and UUID-only
product-selection references, while the current Content AST uses closed
`PSEL-*` references. The safe local implementation binds the current Content
AST and its exact references and marks schema reconciliation as required. It
does not claim formal schema validation or publication readiness.

## Completion boundary

`LOCAL_CODE_COMPLETE` and local integration evidence only. Formal TST-014,
formal TST-021, hosted CI, live/provider, staging, publication, release, and
Production remain `NOT_EXECUTED` and require their Canonical gates.
