# ST-0205 ExecPlan — Synthetic data factory

## Objective

Implement the approved ST-0205 Story as a deterministic, offline synthetic
fixture factory and versioned seed-scenario bundle for all 13 canonical data
domains. Preserve the acceptance boundary: no Rakuten review body and no PII.

## Canonical inputs

- ST-0205 in `RAOS_13_story_backlog_v1.0.yaml`
- RAOS-TEST-001 section 11 and TST-005/TST-031
- RAOS-SEC-001, its data classification catalog, and controls SEC-APP-001,
  SEC-DATA-003/004/007, SEC-SDLC-006
- RAOS-DATA-001's 13-domain schema ownership map
- Current ST-0201 and ST-0202 manifests

The Story has `open_decisions: []`. OD-014 remains unrelated and unresolved;
no retention duration or deletion behavior is introduced.

## Implementation

1. Define a strict source contract that pins dependencies, canonical inputs,
   exact domains, scenario matrix, privacy rules, control mappings, and
   unexecuted boundaries.
2. Implement a pure factory with reviewed domain/scenario inputs, bounded
   deterministic seed derivation, exact payload allowlists, canonical data
   classification handling, structural sensitive-field rejection, secret/PII
   detection, and no external I/O.
3. Generate canonical JSON fixture and catalog bytes. Hash every fixture and
   record its exact origin and repository-authoritative license metadata.
4. Generate a source/output manifest and fail closed on canonical or ST-0201 /
   ST-0202 hash drift.
5. Add isolated contract, factory, edge-scenario, privacy, generation, and
   negative tests. Route only generation/check/test through local Make and CI
   unit/repository-policy boundaries.

## Verification plan

- generator `--check`
- isolated `tests/st0205`
- Ruff format and lint for the new Python sources/tests
- strict repository mypy and Pyright (the factory remains outside runtime
  package scope, so these confirm no affected typed application surface)
- ST-0102/ST-0106 routing tests
- `git diff --check`

Local success supports an implementation candidate only. Formal TST-005 and
TST-031, manual privacy/security review, hosted CI, provider/runtime checks,
staging, production, and status APPLY are not performed by this plan.

## Out of scope

- PostgreSQL/S3 writes, schemas, migrations, or retained seed state
- live or recorded provider data and production/staging copies
- credentials, provider SDKs, network access, or environment loading
- retention-period selection, lifecycle deletion, and OD-014 resolution
- ST-0005 evidence requests or canonical status changes
