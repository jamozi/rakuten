# ST-1901 — model-Judge calibration local ExecPlan

## Objective and authority

Implement the maximum-safe Post-MVP interface for human-label-calibrated model
Judge evaluation. Preserve ST-1901 as `DEFERRED_POST_MVP`; the local runtime has
no provider, model, credential, network, persistence, activation, approval,
publication, release, staging, or Production authority.

## Slices

1. Bind the exact current ST-0707 runtime and Canonical Judge/rubric/security
   sources.
2. Generate 200 opaque, balanced, double-labeled synthetic calibration records
   with explicit non-representative and no-actual-human provenance.
3. Load caller-supplied bytes through a strict provider/model-neutral inward
   port; reject unknown, ambiguous, leaky, duplicate, or drifted material.
4. Compute exact quadratic weighted kappa and critical false rates without
   allowing Judge outputs to mutate human gold labels.
5. Return only refusal outcomes; missing real provenance/scope always blocks
   operational calibration and requires a separate human Release Decision.
6. Generate fixture/report/manifest deterministically, prove no-write drift, and
   run focused and dependency checks.

## Completion boundary

Local completion is code, deterministic generated artifacts, owner check,
focused tests, dependency regression, static/type/compile/secret checks, and a
clean one-Story commit. Formal TST-032, actual human labels, live provider/model,
staging, release, publication, and Production remain `NOT_EXECUTED`.
