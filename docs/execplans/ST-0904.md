## Objective

Implement the Canonical ST-0904 projector at the maximum safe local boundary:
consume the exact ST-0903 V2 immutable snapshot candidate, enforce the ST-0306
public-role boundary and an explicit field allowlist, and produce deterministic
public article/route shapes without activating or persisting them.

## Canonical inputs

- ST-0903 V2 immutable request/result pair and its owner-generated fixture.
- ST-0306 `raos_public_ro` readmodel-only role/grant contract.
- Public API article, block, product, offer, and route shapes.
- Canonical public-isolation/integrity controls SEC-DATA-004/006.

## Implementation boundary

1. Independently rebuild and validate the exact ST-0903 fixture.
2. Project only common, source-backed public fields through closed types.
3. Redact internal refs and omit products/offers whose public row facts are not
   available from the immutable snapshot.
4. Emit a deterministic generation-1 noindex article/route local fixture.
   Disclosure is recorded-synthetic copy, time is the ST-0903 build instant
   rather than a publication fact, and freshness is `UNKNOWN`.
5. Fail closed on field/type/hash/authority/collaborator drift.
6. Expose only provider-neutral process-local ports and a recorded adapter.

No DB/network/job/event/API activation/public serving/CMS/publication/staging/
release/Production capability is in scope. Legacy schema conflicts are recorded
and remain unresolved.
