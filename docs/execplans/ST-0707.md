# ST-0707 — deterministic recorded evaluation harness ExecPlan

## Objective and authority

- Canonical Story: `ST-0707`, evaluation harness.
- Dependency: current ST-0705 deterministic output-validation runtime.
- Local scope: immutable suite/dataset values, strict recorded loader, pure
  metrics and zero-tolerance aggregation, proposal-only report, owner generator,
  fixtures, tests, documentation, and local completion evidence.
- Hard stops: no live provider, credential, human-label invention, production
  data, route/model activation, approval, publication, persistence, staging,
  release, or Production action.

## Implementation slices

1. Pin the Canonical evaluation catalog, dataset/schema/rubric/security sources,
   and exact current ST-0705 runtime/profile/fixture/report bindings.
2. Generate a closed suite registry and a clearly synthetic, non-canonical,
   non-representative, non-human-labeled locked HOLDOUT plumbing dataset.
3. Load bounded canonical artifacts fail closed, recompute all nested identities,
   and re-evaluate the ST-0705 fixture rather than trusting a claimed pass.
4. Compute exact ratio point estimates, one-sided 95% Wilson lower bounds,
   threshold results, and eight no-waiver zero-tolerance observations while
   preserving missing evidence as unavailable.
5. Produce deterministic release-decision proposals limited to
   `REFUSED_ZERO_TOLERANCE` or `REFUSED_INCOMPLETE_EVIDENCE`, with no operational
   authority or action surface.
6. Publish generated outputs through the shared hardened descriptor-relative
   transaction and test rollback, foreign preservation, target races, parent
   swaps, tamper, bounds, and post-load mutation.

## Completion boundary

Local completion requires owner build/no-write check, focused ST-0707 runtime
and historical tests, relevant ST-0705/shared-publication affected tests, Ruff,
strict mypy, compile/import, focused sensitive-data scan, and
`git diff --check`. It does not satisfy formal TST-018/TST-019 or grant live,
staging, publication, release, or Production status.
