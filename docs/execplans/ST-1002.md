# ST-1002 — exact recorded public article SSR

## Objective

Implement the Canonical `PUB-003` article route at the maximum safe local
boundary. Render only the exact ST-0904 V2 public projection fixture through a
closed deterministic model, preserving the ST-1001 server-only/noindex shell
principles and every publication/public-isolation gate.

## Inputs read

- Canonical integration precedence, decisions/open decisions, ST-1002 and
  dependencies ST-0904/ST-1001.
- Public UI/screen/component/accessibility contracts, Public OpenAPI/read-model
  shape, security design and SEC-DATA-004/006, THR-004/018/019.
- TST-021, TST-022, and TST-023 definitions.
- Existing ST-1002 V1 disabled candidate and all adversarial tests.

There is no blocking Open Decision. OD-002 remains safe because this route is
unbranded, has no domain/operator/canonical identity, is noindex, and is local
only. Missing public products/offers/comparison facts are not invented.

## Implementation

1. Preserve the V1 model and append a strict V2 source/view contract.
2. Bind the exact ST-0904 fixture and projection digests in a versioned owner
   contract and deterministic atomic generator.
3. Strip identifiers and downstream surfaces before generating the runtime
   source; validate exact source equality again at runtime.
4. Register one force-dynamic `/articles/[slug]` server route. Resolve only the
   recorded slug; return a non-reflecting 404 otherwise.
5. Render escaped text, one H1, skip/breadcrumb/landmarks, explicit disclosure,
   preview/freshness states, and responsive source-backed sections.
6. Apply local-preview noindex/CSP/no-store headers without changing the
   ST-1001 policy-route config or generated artifacts.
7. Verify pure/negative/generated/static/a11y, Next build, loopback SSR,
   320/360/768/1440 reflow, keyboard focus, axe, and affected predecessors.

## Out of scope

Products, offers, images, CTA, comparison data, JSON-LD, canonical URL, live
read model/API/DB/provider access, analytics/tracking/cookies, operator/site
identity, publication, staging, release, Production, and Registry APPLY.

## Completion boundary

`LOCAL_IMPLEMENTATION_COMPLETE` with reproducible local evidence. Formal
TST-021/TST-022/TST-023 and manual assistive-technology evidence remain
`NOT_EXECUTED` and are not inferred from local browser checks.
