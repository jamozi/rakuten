## Audit remediation

The independent audit first confirmed 258 tests but found three High and four
Medium issues. The final core pass addresses all of them:

- per-dump forced model rebuild became locked one-time readiness used by both
  load and dump;
- blocking, unbounded pinned reads became nonblocking and exact-size bounded;
- post-dump policy now uses a reprojected serialized snapshot;
- general JSON `ValueError`, including Python's oversized-integer limit, is
  redacted;
- generated imports use mypy `silent`, not `skip`;
- RFC3339 leap-second syntax reaches the generated model boundary instead of
  being mislabeled as a schema failure; and
- root-title pseudo coverage became an explicit block-field and deferred-row
  mapping.

A later bundle audit identified an overbroad generated-integrity claim. The
implementation now records that selected runtime file parity occurs only after
normal Python import, leaves pre-execution integrity with the ST-0105 gate, and
checks all 354 outputs in the pinned ST-0105 manifest during ST-0801 manifest
generation. The source closure also includes the executed root package
initializer, root pytest bootstrap, and shared generator helper.
The final transitive source closure also pins the ST-0102 pytest bootstrap and
the CI workflow that invokes the exact ST-0801 gate, for 94 unique inputs.

The current ST-0105 generated `AwareDatetime` cannot represent a valid leap
second such as `2016-12-31T23:59:60Z`. The loader therefore returns a redacted
`MODEL` failure after schema acceptance. No generated output was edited and no
semantic normalization was invented.
