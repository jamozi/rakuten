## Remediation record

The independent review found four issues before the final PASS: YAML scalar
type confusion, manifest-install symlink/ancestor races, missing runtime
validation for `QueueDelivery.message`, and timestamp-overflow state loss.
All four were fixed with focused negative tests. The full static gate then
found a formatting drift and strict-Pyright boundary annotations; those were
fixed without removing the runtime defenses, and the complete static gate was
rerun to PASS.
