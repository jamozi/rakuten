# ST-0505 worklog — bounded live Rakuten smoke implementation

## Scope

This implementation adds a disabled-by-default, staging-only executable boundary for the canonical ST-0505 live smoke. It does not modify the existing non-executable reference plan, ST-0502 recorded-only types, Canonical status, OD-015, TST-016 execution status, credentials, provider state, staging, publication, release, or Production.

## Runtime boundary

- Current official Rakuten Ichiba Item Search endpoint: `https://openapi.rakuten.co.jp/ichibams/api/IchibaItem/Search/20260701`.
- Exactly one HTTPS GET, page 1, one hit, standard sort, no affiliate ID, no retry, no pagination, no persistence, and no publication.
- Access Key is sent only in the `accessKey` request header; App ID is sent as the required `applicationId` query parameter.
- System CA verification is retained. Proxy inheritance and redirects are disabled. Response size, JSON depth, JSON nodes, duplicate keys, UTF-8, media type, schema, and URL fields are bounded and validated.
- Activation requires a staging-only, request-hash-bound grant with a maximum 15-minute lifetime and two externally supplied evidence digests. The code does not claim that either digest approves or resolves Canonical authority.
- Credentials are injected through fixed aliases and have redacted string/repr/pickle behavior. No CLI or environment reader is added.
- Success returns a sanitized receipt containing request/response hashes and bounded observations only. Raw provider data, credentials, and the search keyword are absent from the receipt.

## Verification

The no-network suite uses fake credentials, a fake clock, and a fake transport. It covers success, exact request shape, secret redaction, expired/mismatched grants, missing credentials, redirects, 4xx/429/5xx, transport ambiguity, malformed UTF-8/JSON, duplicate keys, non-finite numbers, body/depth limits, content-type/encoding drift, schema drift, and rate-header absence/partial presence. Every post-attempt failure asserts one transport call and therefore zero retries.

Formal live TST-016 remains `NOT_EXECUTED`; a real provider request remains an external Operations action after OD-015 evidence and explicit execution approval.
