### Implementation notes

- The reviewed handoff limit is 8 MiB. YAML depth 64 and node 100000 are
  enforced during composition before Python containers are constructed and
  checked again after construction. The node budget is global to the input,
  and a second document is rejected before its graph is constructed; exact
  single-document boundaries and first-over inputs fail deterministically.
- Repository text and archive/member reads use the pinned 16 MiB and 131072-byte
  limits through explicit path routing. The archive's 369 regular members sum
  to 5,679,757 uncompressed bytes under the reviewed 6 MiB cumulative limit,
  which is below the 369-member per-member theoretical aggregate.
- Oversized candidates report a digest of the bounded bytes actually read and
  candidate_sha256_complete: false; they never claim an exact full-file hash.
- Structured archive-member references are bound to the pinned V2 archive and
  require archive_path, archive_sha256, member_path, and member_sha256.
  Members must be safe, present, regular, and hash-verified. The approved input
  member is checked against both this contract and V2 manifest metadata.
- Candidate payloads require the eleven repository-mandated fields. Authority
  and approval sections are optional and use the contract-compiled normalized
  grammar/value classes. Root claims and mapping/list claims below a root
  boundary section are checked; only proposal, pending, blocked, not-granted,
  not-executed, null, and the rule's explicitly denial-capable false forms are
  accepted for their respective claims. Harmless ordinary structures and
  boundary prose remain accepted; nested, mixed-case, or separator-variant
  approval/authority claims inside a boundary section fail.
- The independent test fixture hard-pins all 103 physical table relations,
  the one view, the 27 lock_version relations, the 24 reconciled
  STATE_CAS_WITHOUT_LOCK_VERSION relations, all limits, source/hash tuples,
  archive tuple/counts/bytes, and V2 source/owner-approval identity. It parses
  the hash-pinned catalogs and physical fragments only to assert physical
  equality and absence of `lock_version` from the state-CAS set before building
  the pass candidate.
- Archive compressed-file reads and archive-member reads have independent
  exact/+1 tests; member reads remain bounded by 16 MiB while cumulative
  regular-file accounting remains independently capped at 6 MiB.
- Invalid CLI forms produce exit 2, one sorted compact JSON line, and empty
  stderr. A one-byte contract mutation in a disposable root produces the
  trusted `validator_contract_digest_mismatch` error without touching the real
  repository.
- Automated checks stop at byte/shape/inventory facts. D2/D4/D5/D6 semantic
  topics are explicitly MANUAL_REQUIRED in reports and documentation; prose
  and weak lexical checks cannot pass or reject those topics.
- V2 manifest approved source_path and owner_approval_statement_sha256 are
  cross-validated against declarative contract values.
- No-write coverage copies the exact trusted closure into a disposable
  repository root with an unrelated sentinel, snapshots the complete temp
  tree including path/type/mode/size/mtime/hash, and compares before/after.
  Symlink and FIFO probes run only in disposable roots; validator subprocesses
  set PYTHONDONTWRITEBYTECODE=1 explicitly.
