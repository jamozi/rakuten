The committed `.npmrc` fixes registry, cache, strict peer/engine handling,
exact saves, lock behavior, and disabled lifecycle scripts. Make separates
intentional lock generation from locked sync and check operations. Its
aggregate check performs a locked install, exact version checks, complete

Pyright, and the isolated Vitest suite. A fresh offline command installs into
a temporary workspace from the hydrated fixed cache with network disabled and
compares normalized installed trees byte-for-byte.

`scripts/node_toolchain.sh --node ABSOLUTE_PATH --npm-cli ABSOLUTE_PATH
COMMAND` is the recorded-evidence entrypoint. It starts privileged Bash with a
fixed system path, canonicalizes the exact Node/npm/prefix/repository paths,
requires npm to belong to the selected Node prefix, rejects path characters
that Make or a child shell could reinterpret, accepts a fixed command
vocabulary, clears inherited Node/npm/shell/Make controls, and invokes the
physical repository's relative Makefile through an allowlisted environment.

Storage gates reject symlink or non-regular fixed inputs, cache/deletion
targets, workspace parents, and workspace manifests before `npm ci` can
remove or rewrite anything. The Story-local suite covers exact pins, lock
provenance and integrity, manifest drift, dependency-tree consistency,
lifecycle suppression, online/offline equality, unsafe storage shapes,
repository paths with spaces, tool-path canonicalization, and inherited
startup/Node/npm/Make/path controls. Product routes, components, generated
contracts/types, CI, browser behavior, providers, credentials, and deployment
were not added.

The lock check now runs a deterministic Node-built-in-only manifest preflight
before `npm ci`. It accepts only the root and three fixed workspace package
paths, rejects relative, escaping, duplicate, non-regular, and symlink inputs,
and compares presence plus canonical JSON values for ten supported lock-owned
metadata fields against package-lock v3. It also validates the derived
`hasInstallScript` bit from `preinstall`, `install`, and `postinstall`. The
preflight requires the exact five-key package-lock v3 envelope,
`requires: true`, top-level name/version equality with the root manifest,
object-valued package entries, and no non-`node_modules` location beyond the
fixed workspace set. The fixed manifests intentionally omit bundle or accept
dependencies, funding, platform constraints, bins, and deprecation metadata;
their presence, including the bundled-dependencies alias, fails closed rather
than duplicating
npm's normalization. npm-internal integrity/shrinkwrap fields are not public
manifest inputs and remain outside this preflight; registry integrity and
locked outcomes retain separate existing checks. Non-lock-stored overrides
retain their exact static and outcome checks. Valid inputs continue to exact
`npm ci --dry-run`, preserving npm as the semantic backstop. Stale negative
fixtures therefore fail on explicit metadata mismatch before npm's lock
semantic check makes a registry attempt; the wrapper's environment scrub and
lock hash guard remain unchanged.

The Node Pyright target no longer triggers `python-sync`. Node `pyright` and
`check` require an exact `.venv` independently hydrated through the Python
wrapper, then perform a read-only guard before Pyright: `.venv` and `.venv/bin`
must be physical directories, the resolved Python leaf must be an executable
regular file, and an isolated probe must report CPython 3.14.6 with the exact
virtual-environment prefix. The Node wrapper ABI remains Node/npm-only. The
guard-to-execution boundary must not race another same-UID process replacing
the interpreter.
