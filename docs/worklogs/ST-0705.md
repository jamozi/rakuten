# ST-0705 implementation worklog

## 2026-08-24 — recorded deterministic validator V1

- Preserved the historical reference-only candidate and added a separate local
  runtime with immutable DTOs and a pure `evaluate_ai_output` entrypoint.
- Added twelve exact generator-owned task profiles.  Each binds ST-0701 task,
  prompt, schema, route and registry hashes, explicit JSON locators, alignment
  obligations, task/prompt runtime checks, and required semantic receipts.
- Added canonical JSON, Draft 2020-12 plus format checking, canonical UUID,
  resource membership/identity, number/date/unit/currency/tax/text, ordering,
  affiliate-influence, forbidden/review, secret, size/count, and hash/version
  gates.  Positive pattern matches can block, but absence never substitutes for
  a hash-bound taint, review, policy, or sensitive-data receipt.
- Kept ST-0703 provider exchange hashes separate from raw and canonical output
  hashes.  Noncanonical JSON is not silently relabelled canonical, and a
  4 MiB+1 valid JSON document reaches the terminal oversize classification
  before parsing rather than the repairable invalid-JSON path.
- Added exact ST-0605 Article/body/Packet/Claim/evaluation/report binding.
  Valid coverage `BLOCKED` is a proven block; corrupt, mismatched, unsupported,
  or absent binding is `UNEVALUABLE`.
- Recorded the AIT-004, AIT-005, and AIT-009 frozen-schema/alignment gaps as
  mandatory semantic limitations.  No successor schema or Content AST fields
  were invented.  AIT-011/012 remain recorded/default-disabled.
- Added closed failure disposition (`NO_FAILURE`, `ONE_REPAIR_ELIGIBLE`,
  `TERMINAL_BLOCK`, `UNEVALUABLE`) without adding provider repair behavior.
- Added a strict content-addressed registry loader, recorded reader, local
  application service, deterministic fixture, robust transactional generator,
  and focused negative-path/security tests.  Reports serialize hashes and
  closed findings only; raw output is never serialized.
- Formal TST-019/TST-020, live provider, staging, release, publication, and
  Production remain `NOT_EXECUTED`.
