## Finding ST1204-AUDIT-001

The generated bytes, provenance pins, provider semantics, closed synthetic
allowlist, schema validation, and read-side captured-source checks passed the
independent review. The publication implementation did not pass.

At the audited bytes, `_ensure_output_parent` validates output ancestors with
full-path existence and `lstat` checks. `_atomic_write` subsequently uses a
full-path `mkstemp`, `os.replace`, and parent-directory `os.open`. A concurrent
same-UID mutator can replace a previously checked ancestor between those
operations, so the write is not confined to the captured directory identity.

The generator also publishes three fixture files and one manifest through four
sequential file replacements. An injected failure or process crash can
therefore leave a mixed old/new artifact set. The existing happy-path test
proves only that the final files exist and no ordinary temporary file remains;
it does not prove bundle atomicity, ancestor-swap confinement, rollback, crash
recovery, or lock ownership.

## Required closure

Closure requires an approved artifact/publication design, an implementation
through `implementation_worker`, fault-injection and concurrency coverage, the
full local isolated ST-1204 gate, and a fresh independent read-only audit. A
local PASS after that work still does not constitute formal TST-030, live,
staging, privacy-approval, or production evidence.
