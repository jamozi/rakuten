## Live evidence still required

Enforcement remains forbidden until a single reviewed evidence pack proves:

1. the authenticated repository and actual default branch;
2. each listed team is real, visible, and has explicit write permission;
3. each required check's exact context and expected GitHub Actions App ID from
   a successful run in that repository;
4. the complete authenticated effective ruleset state, including parent rules
   and visible bypass actors;
5. positive and negative PR/direct-push probes for every declared policy; and
6. distinct human approval of bindings, API diff, read-back, and probe results.

The generated ruleset candidate must never be submitted directly. A future,
separately approved runbook must replace symbolic values with authenticated
numeric bindings, show the final payload diff, apply it, read it back, and
retain rollback evidence.
