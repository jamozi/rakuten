# ST-0304 ExecPlan - domain schemas

## Outcome and boundary

Implement the approved Portfolio, Catalog, Evidence, Editorial, AI, and Policy
physical database slice after ST-0303 as a local implementation candidate.
Canonical status remains `NOT_STARTED / NOT_EXECUTED`; no status request or
formal evidence is owned by this worker.

The effective six-schema catalog contains 86 tables and 1,141 columns and
includes the finalized INT-DEC-004 and INT-DEC-005 database resources. The
eleven adopted content tables remain RLS-enabled and forced, intentionally
fail-closed with zero policies. Publishing/readmodel/freshness/analytics/
finance, workload roles, grants and role-bound RLS policies, seeds,
repositories, services, providers, and publication are outside this Story.

## Plan

1. Verify the pinned predecessor and exact baseline/overlay source inventory.
2. Generate bounded cumulative Alembic revisions, catalog, validation SQL, and
   manifest from the source contract and physical translation fragments.
3. Advance the checksum-bound migration catalog and installed-shape validator.
4. Add isolated static and exact PostgreSQL 18.4 fresh/predecessor/downgrade/
   re-upgrade/catalog/constraint/index/trigger/data-negative tests.
5. Route the cumulative `migration-generate`, `migration-check`, and
   `migration-test` targets to ST-0304, add its isolated suite to `ci-unit`,
   and retain `ci-static` coverage through `migration-check`.
6. Run exact uv 0.12.1 locked/offline/no-cache/no-sync checks and, when the
   reviewed cached runtime is used, exact PostgreSQL 18.4 checks. Report all
   local results only as candidate evidence, separately from formal TST-008 and
   TST-010 validation.

## Invariants

- All tables are rendered before cyclic foreign keys; the deferred
  `ops.job.site_id` reference is connected only after an orphan preflight.
- Finalized ST-0003/ST-0004 checkpoints are provenance, never concatenated or
  executed as this migration.
- Downgrade locks the owned tables, proves them empty, and drops with
  `RESTRICT`; rollback failure is atomic.
- No unresolved Open Decision is inferred.
