## Remediation record

Independent review found fail-closed boundary defects before the final PASS:
structured Pydantic and pickle surfaces could retain rejected input, inherited
model/reference overrides could survive revalidation, generated `$` patterns
accepted a trailing line feed in the repository Python validator, and the
supported JSON entrypoint accepted duplicate members through last-wins parsing.
Those paths now sanitize before validation, forbid subclassing, revalidate and
normalize existing instances, use cross-engine absolute-end schema patterns,
and pre-scan every bounded JSON object for duplicate members. Mutable bytearray
input is snapshotted once before that parser pipeline. Focused regressions,
Python Draft 2020-12 validation, Node regular expressions, toolchain provenance,
descriptor-relative generation, and the full gates were rerun without reducing
the security boundary.
