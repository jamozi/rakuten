## AI指摘の処理

起動設定は R10 gpt-5.6-sol（初めて選ぶ読者）、R11 gpt-5.6-terra（家庭の費用）、R12 gpt-5.5（購入直前）、R13 gpt-6-astra（根拠精査）、全員reasoning=high。別コンテキストで同じ390px表示版・固定冒頭抜粋を使用した。冒頭回答を保存してから全文を渡し、外部の商品知識を根拠に足していない。

| 指摘 | 採否・照合・修正 |
| --- | --- |
| 費目欠損時に総額と誤読する可能性 | 採用。結果側の小計/未計算表示は既実装で、固定資料に計算後画面がなかった。入力前にも「未確認は0円ではない」「含む費目が違う額は比較できない」を追加。実ブラウザーで計算後の正常・水量のみ・UNKNOWNの表示を確認済み |
| 仕様欄の水量を同じコースとして横比較しそう | 採用。表直前にコース条件が揃わず水量だけの横比較に使えないと明示。量・単位は変更しない |
| 未確認セルに公式確認済みバッジが併記される | 採用。寿命の補助表ではバッジを省き、値の未確認表示と型番別公式出典を残す。claim参照の検証は継続 |
| 寿命順位・年数換算しない説明が表から遠い | 採用。データ駆動の補助表noteを表直前へ追加。保証期間とも区別 |
| 出典取得日・記事確認日・個別確認日が紛らわしい | 採用。冒頭のラベルを出典取得日と記事確認に分離、末尾で各項目の確認範囲を案内。9月5日等へ一括統一する提案は不採用。実際の取得日を置換できないため |
| 販売リンクなしと広告開示の掲載しますが矛盾して見える | 採用。offer非表示時は、後続が販売リンクを掲載する場合の広告方針であることを付記。広告方針・リンク条件は維持 |
| 未確認機種Whの補完、手洗い差額、寿命順位を知りたい | 保留。今回の資料から値を生成しない。計算可能なことを商品推薦の優位性としない |

独立コードレビューでは、assetの許可パス漏れ、表示コースの自由上書き、アーカイブID衝突を修正し再レビューした。寿命表のUNKNOWNと見出しを扱う意味検証は閉じた文言・構造の範囲だけを追加し、数字を含む任意の未確認文や表題を無条件に免除しない。開発用読者ledgerの照合は本番用の別人承認ではない。

追加の独立コードレビューで、小数回数が浮動小数点の丸めによって整数と認識される例と、操作検査が古い配信JSで合格できる例を修正した。回数は文字列の整数書式から検証し、検査は配信JSと編集元のSHA一致を必須にした。修正後の再レビューは追加指摘なし。
