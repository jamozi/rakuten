## Before/After で示した判断と既知の差

- 551 の「開いた扉の奥行」の起点は、公式図で確認できたのが AQUA ADW-L40B だけ。パナソニックは設置案内の図の「背面の壁から58.4cm以上」(代替テキスト「寸法には0.5cmのあきを含んでいます」) から 0.5cm を引くと仕様値 57.9cm と一致するが、編集部の引き算なので確認済みとはしていない (549 の SOLOTA の 48.5＋1.7＝50.2 と同じ扱い)。シロカは寸法図の画像が 2026-09-16 に取得できず (HTTP 503) 未確認。
- 「約」の付け方は、メーカーごとに公式表記が割れている。550 は「約76cm」、551 は「72.0cm」。表の 1 セルで表記が混ざらないよう、全体の規則を決める判断が残る。本体寸法 (310×225×435mm など) の「約」も、機種ごとの公式表記を確認し直す必要があるため今回は入れていない。
- 19 は 553 への入口が 1 本増えた (1→2 本) だけで内容更新日が進む。/updates/ は「誤字・見た目の修正や価格だけの再取得では内容更新日を進めません」と書いているので、入口を取りやめるか、2 本の役割が重ならない文言にしてカードに書くかの判断が残る。84 は 0→1 本なので該当しない。
- 375px でだけ、553 の航空会社表の見出しセル (「ジェットスター・ジャパン（GK）国内線・国際線」scrollWidth 87 / clientWidth 85) と 82 の外寸のセル (110 / 108) が 2px はみ出す。W4a の本文と CSS (`ad936713`) で測っても同じ 2 セルが同じ量はみ出し、320/360/390/1440px では 0 件なので、この候補が持ち込んだものではない。どちらのページも横スクロールはしない。
- 83 の「通常時外寸（幅×奥行×高さ）」は、公式が軸名を示していない型番にも付いている。4 型番を再取得した結果が割れた (LIEVE だけ公式に軸名がある、PROTECA は公式ページに仕様表が無い) ため、4 型番を 1 つの規則で決められるまで保留にし、注記で機種ごとに出どころを書き分けた。82 は同じ見出しを使うが公式ページを再取得していないので未確認のまま。
- `#maintenance-suitcase-table` の先頭列で「FREQUENTER」が語中で折り返す。先頭列を広げるとデータ列 1 つ分が枠に残らなくなるため、レイアウトの判断としてオーナー項目に残した。
