## 規約とヘルプの根拠

### バリューコマース / Yahoo!ショッピング — 試行の条件を満たす

- 利用規約: 広告コード・画像・文言の改変は「当社または広告主が認める場合を除き」禁止 (http://www.valuecommerce.ne.jp/st_affiliate/terms.html)。
- ヘルプ「広告コードは改変できますか？」(/aff/ad/adlink/09/): 改変は不可。target・rel・alt・media 属性の追加は改変にあたらない。それ以外の変更や一部抜粋はトラッキング不具合の原因になる。
- ヘルプ「自由テキストリンク広告の『自由テキスト』部分」(/aff/ad/adlink/07/): 商品名などを自由に設定できる。文字数制限なし。
- Yahoo!ショッピングの MyLink 詳細 (http://vcmylink.com/yahooshopping/index.html、プログラム詳細で「必ずご確認ください」と指定):
  - MyLink 広告タグのリンク部分 `http://ck.jp.ap.valuecommerce.com/servlet/referral?sid=…&pid=…&vc_url=` に URL エンコードした商品 URL を付ける方法を公式に説明している。
  - **リンクと併せて 1×1 の計測画像 `ad.jp.ap.valuecommerce.com/servlet/gifbanner?sid=…&pid=…` の掲載が必要** (表示回数の計測のため)。
  - リンク先に使えるのは shopping.yahoo.co.jp / store.shopping.yahoo.co.jp / search / topics / PayPayモール以下。
  - 画像はストアページの商品写真だけ可。ストアロゴ・ストア写真・MyLink 非許可ストアの画像は禁止。
  - MyLink 設定禁止ストア (デルコンピュータ、n-gardenフラワーショップ、喜信堂)、指定テキスト必須ストア (モロゾフ)、画像禁止ストア (園芸ネット、ディノス、オットージャパン、セシール)、訴求禁止商品 (計量法違反の計量器)。
  - Yahoo!ショッピング API で MyLink を作る場合は、バリューコマース商品検索 API のガイドラインに従う。
- バリューコマース・ウェブサービス ガイドライン (2020-06-15 改定、PDF): 商品画像・説明・価格などをウェブサービスの情報掲載以外に転用しない。データの正確性は保証されない。価格の保存期間の定めは無い。

結論: 独自の文言 (自由テキスト) + 公式手順の vc_url リンク + 1×1 計測画像の併載で、規約上の明文に沿って掲載できる。画像は使わない。計測画像の読み込みはプライバシーポリシーへの記載が要る。

### リンクシェア / au PAY マーケット — 試行から外す

- 参加規約: リンクシェア提供物を「当社が容認する箇所を除き」改変しない (https://www.linkshare.ne.jp/LS/agreement.html)。
- au PAY マーケットのプログラム別基本提携契約 第5条1項: 「リンクコードに修正、変更を一切加えてはならない」(http://merchant.linksynergy.com/jp/fs/declares/46164_1122737.txt)。
- ヘルプ「テキストリンクの文言は変更できますか？」(https://linkshare.zendesk.com/hc/ja/articles/360007911533、2024-04-06 更新): フォント・サイズ・色は変更可、テキスト文言は「原則禁止」。EC サイトに要望すれば許可される場合がある。
- ヘルプ「アフィリエイトとしての禁止事項」: 取得したリンクの加工 (テキストコピーの加工を含む) を禁止。
- ヘルプ「SNSへのアフィリエイトリンク掲載方法」: URL 単体の貼り付けでもクリック計測される (SNS 向けの説明)。

結論: 購入部品は「販売先で確認」など独自の文言でリンクを出すため、文言変更の許可を EC サイトから書面で得ない限り条件を満たさない。オーナー決定「明文が無い点は試行から外す」に従い、今回の試行対象にしない。
