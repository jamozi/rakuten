比較記事と同じ機種で、設置を確認できます。型番と使う条件をそろえて照合してください。

購入前に測る順番

  1. 置きたい場所の幅・奥行・高さを測ります。本体寸法だけでなく、給水や食器の出し入れに使う場所も書き出してください。
  2. 型番の欄で、扉を閉じた本体寸法と、扉を開いたときの寸法を別々に確認します。蛇口や棚に当たらないか、扉を動かす範囲も確認してください。
  3. 上・左右・背面の必要余白を型番ごとに照合します。上に必要な空間と、設置場所全体の高さを混同しないでください。
  4. 排水ホースの行き先、電源・アース、水平で安定した台を確認します。数値の欄に収まっても、これらが確認できなければ設置可能とは判断できません。
  5. 不明な条件が一つでも残る場合は、その寸法や接続条件を販売店・メーカーへ確認してから購入を決めます。以下の機種別欄から、確認した公式資料へ進めます。
