# 公開記事の更新情報表示

## 目的と採用したデータ経路

読者が公開記事の更新日時と鮮度を確認できるよう、
`python/raos/application/publishing/public_update_notice.py` に
`render_public_update_notice(projection) -> str` を追加する。

採用する経路は「承認済み immutable publication snapshot → 既存 public projection
→ 表示関数 → 公開側の表示」である。関数は渡された projection の
`article.updated_public_at` と `article.freshness_status` だけを表示値として読む。
取得・承認・投影は既存の上流境界が担い、表示関数から snapshot や内部 repository を読まない。
この変更は関数の追加であり、公開 API・Web・WordPress への接続や公開操作は行わない。

両項目は既存 `PUBLIC_ARTICLE_FIELDS` にあり、Public API の生成型でも
`freshness_status: string`、`updated_public_at?: string | null` と定義されている。
新しい公開フィールド、出典情報、schema、projection version を追加する必要はない。

## 比較した案と理由

内部 Evidence の確認日時や Finance の処理日時を直接読む案は採用しない。
それらは記事の公開更新日時ではなく、承認済み snapshot と表示内容が食い違う原因になる。
また、公開側の内部 Evidence・Finance・raw AI への直結を禁じる境界に違反し、
内部情報の流出や財務と編集判断の混同を招く。既存の公開済み値で要求を満たせるため、
内部データへの依存や公開契約の拡張は不要である。

## 表示と欠損時の動作

- 戻り値は `更新: <article.updated_public_at> / 状態: <article.freshness_status>`。
  各値を標準ライブラリの `html.escape` で escape し、`&`、`<`、`>`、両引用符を無害化する。
- projection と article は mapping、2 項目は空白だけではない文字列を要求する。
  構造の欠損・不正、キー欠損、`None`、空文字、空白のみ、非文字列は `ValueError`。
  エラー文には入力値を含めない。
- 日時の変換、鮮度の再判定、現在日時・`published_at`・内部情報での補完はしない。
  `UNKNOWN` は公開値としてそのまま表示する。日時形式や状態の列挙値の検証をここで追加しない。
- 入力を変更せず、他のフィールドを出力しない。DB・network・CMS・ログ出力を使わない純粋関数とする。

## 隣接影響

現在の ST-0904 V2 合成 projector は `updated_public_at=None`、
`freshness_status="UNKNOWN"` を返す。そのままではこの関数は `ValueError` となる。
これは表示の必須値がない場合の要求どおりであり、既存 projection が不正という意味ではない。
将来の利用側は、この表示が更新日時を持つ記事に適用できることと欠損時の例外を扱う必要がある。
回帰テストの正常系だけに合成日時を設定し、生成元・生成 fixture・既存の nullable 契約は変更しない。

snapshot の承認・hash binding、projection の閉じた allowlist、public/internal 分離、
API 権限、CTA、広告表示、publication・kill switch の動作は既存の境界に残る。
本関数は承認検証や projection 全体の検証を代替せず、公開権限や副作用を追加しない。
Web 契約、DB、generator 入力・出力にも変更はない。

## 根拠

- `AGENTS.md`: 公開側は承認済み snapshot の public projection を読む不変条件。
- `docs/architecture/current-system.md`: Data flow and ownership と公開契約の閉鎖性。
- `python/raos/domain/publishing/public_projection_v2.py`: `PUBLIC_ARTICLE_FIELDS` と既存の投影値。
- `changes/st-0904/contracts/public-projection-runtime.v2.yaml`: allowlist と内部情報の隔離。
- `packages/web-contracts/src/generated/clients/public/types.gen.ts`: 既存 PublicArticle の型。
